# About these notes

This site collects my notes as I learn **Haskell** and **category theory**.

The pages are written in Markdown, rendered to HTML with
[Hakyll](https://jaspervdj.be/hakyll/) (a static site generator written in
Haskell — fitting), and published automatically to GitHub Pages on every push.

LaTeX math is rendered by MathJax, so I can write things inline like
$\eta : 1_{\mathcal{C}} \Rightarrow G \circ F$ or as display equations:

$$
\mathsf{Hom}_{\mathcal{D}}(F\,A, B) \;\cong\; \mathsf{Hom}_{\mathcal{C}}(A, G\,B)
$$
